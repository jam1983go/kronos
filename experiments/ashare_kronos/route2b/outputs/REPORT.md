## 结论

判断模型已经训成。退出日早于 2025-01-15 的合格 HIT 单笔有 704 笔，盈利 322、亏损 382，超过事先的 80 笔和每类 25 笔。第一批 94 只股票、2018 年起的样本就够用，没有扩到 2016，也没有加入第二批。

主比较是同一套量价特征、C=1 的 logistic。2022–2024 三折合并后，不含 Kronos 为 12/32 = 37.5%，平均净收益 -1.6%，profit factor 0.43；含 Kronos 为 18/41 = 43.9%，平均净收益 -0.4%，profit factor 0.79。胜率高 6.4 个百分点，日期区块区间是 -2.2 到 +15.7 个百分点，包含 0。两边期望都为负，所以按事先标准是无效，不能因为胜率更高就采用。

探索性再验证里，不含 Kronos 是 3/15 = 20.0%，含 Kronos 是 4/16 = 25.0%，高 5.0 个百分点，区间 -1.8 到 +12.5 个百分点。平均净收益分别是 -4.2% 和 -3.8%，profit factor 都约为 0.33。判定为无效。

只看 Kronos 符号、不经 logistic 的过滤器，在走步合并里胜率 51.4%，比未过滤的 40.8% 高 10.5 个百分点，区间 -1.3 到 +21.7 个百分点；平均净收益仍是 -0.1%，profit factor 0.92。未过滤研究近似本身是 40/98 = 40.8%，平均净收益 -0.8%。深度 2 的树在再验证里只有 3 笔且都盈利，覆盖率 1.6%，不构成成功。

因此：模型训成了，Kronos 的点估计略抬高胜率，但没有达到事先的增量标准，也不能实施。方向准确率和交易胜率已分开列出。池子按 2019–2021 成交额筛选，名单仍有存活偏差。Kronos 训练截止不可审计。下一步不做全量微调。
